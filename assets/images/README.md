# Изображения проекта

В этой папке находятся локальные изображения, используемые страницей.

Планируемые материалы:

* исторический визуальный материал Netscape Navigator;
* исторический материал Windows 95;
* один или несколько скриншотов веб-страниц 1996 года;
* дополнительные небольшие графические элементы, соответствующие эпохе.

Все изображения должны иметь понятные имена и относительные пути.

Источник каждого изображения фиксируется в `sources.md`.

Файлы с компьютера пользователя не должны подключаться через абсолютные пути вида:

`C:\Users\...`

Для сайта используются только относительные пути внутри проекта.
