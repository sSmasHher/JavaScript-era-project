JavaScript как артефакт эпохи
Лабораторная работа

Вариант: 25
Объект исследования: JavaScript
Тип объекта: язык программирования

Выбранная эпоха

1995–1997 годы — период появления JavaScript в Netscape Navigator, начала распространения JavaScript в браузерах и первичной стандартизации ECMAScript.

Идея проекта

Рекламная веб-страница вымышленных курсов по JavaScript, созданная так, как она могла бы выглядеть для пользователя раннего коммерческого веба второй половины 1990-х годов.

Проект показывает JavaScript не как современный универсальный язык разработки, а как технологию, которая помогала превращать обычную веб-страницу в интерактивную программную среду.

Структура проекта
research.md — историческое исследование JavaScript.
era.md — обоснование выбранной эпохи и её визуальной среды.
concept.md — концепция вымышленных курсов.
sources.md — исторические и визуальные источники.
blocks/ — самостоятельная структура смысловых блоков будущей страницы.
PROMPT.md — инструкция ИИ-агенту по сборке сайта.
iterations.md — план и фиксация двух обязательных итераций.
assets/ — локальные материалы страницы.
index.html — финальная веб-страница.
Основная логика

ИСТОЧНИКИ → ИССЛЕДОВАНИЕ → ЭПОХА → КОНЦЕПЦИЯ → БЛОКИ → PROMPT → INDEX.HTML → ИТЕРАЦИИ

Результат
