# Итерации

## 1. Эпоха и визуальная точность

### Проблема

Первая версия страницы может выглядеть слишком современно, даже если содержит исторические факты.

Особенно вероятны современные решения: большие карточки, чрезмерно свободная композиция, современные кнопки, градиенты, современная типографика или визуальная структура SaaS-лендинга.

### Инструкция агенту

Проверь `index.html` по `era.md` и `sources.md`.

Усиль историческую достоверность страницы 1995–1997 годов.

Проверь:

* типографику;
* плотность информации;
* прямоугольные блоки;
* рамки;
* кнопки;
* ссылки;
* цвет;
* размер изображений;
* композицию;
* отсутствие современных UI-приёмов.

Не меняй исторические факты и не добавляй новые смысловые блоки.

### Что изменилось

1. **Удалён `box-shadow`** с основного окна браузера — современный эффект тени, не существовавший в 1996 году.
2. **Замён `display: flex`** на `display: table` в панели браузера — flexbox появился только в 2009 году, в 1996 использовали таблицы.
3. **Кнопка «ЗАПИСАТЬСЯ»** перекрашена из синей в серую (`#c0c0c0`) с чёрным текстом — соответствует стилю Windows 95. Удалён hover-эффект с изменением цвета фона.
4. **JavaScript `alert()`** замён на ссылку `mailto:` — в 1996 году системный alert выглядел иначе, а текст внутри был слишком современным. Ссылка на почту соответствует эпохе.
5. **Уменьшены отступы** во всех блоках: `padding` с 10–12px до 4–8px, `margin` с 10–16px до 3–6px — композиция стала плотнее, как в 1996.
6. **Убраны пунктирные рамки** у плейсхолдеров изображений — заменены на сплошные тонкие рамки, характерные для эпохи.
7. **Приглушены яркие цвета**: жёлтый фон `#ffffcc` заменён на белый, жёлтый текст в блоке «Будущее» заменён на белый.
8. **Замён шрифт "MS Sans Serif"** на `Arial, Helvetica, sans-serif` во всех местах — MS Sans Serif не был стандартным веб-шрифтом, Arial более аутентичен для 1996 года.
9. **Уменьшены размеры шрифтов** на 1–2px везде — типографика стала компактнее.
10. **Добавлен `border: 1px solid #000000`** на таблицу сравнения браузеров — характерный приём 1996 года.

### Почему результат стал точнее

- **Табличная структура** вместо flexbox соответствует методам вёрстки 1995–1997 годов (источник: Web Design Museum — Websites in 1996).
- **Серая кнопка** с рамкой outset/inset соответствует стилю Windows 95 (источник: Microsoft — Launch of Windows 95).
- **Плотная композиция** с малыми отступами соответствует характеристике раннего коммерческого веба из era.md: «плотная компоновка», «ограниченное количество визуальных материалов на одном экране».
- **Отсутствие теней, скруглений, градиентов** соответствует списку запрещённых элементов из era.md.
- **Шрифт Arial** был системным шрифтом Windows 95 и доступен в браузерах того периода.
- **Ссылки `mailto:`** были стандартным способом связи в 1996 году, в отличие от современных форм.

## 2. Смысл и история объекта

### Проблема

После визуальной правки страница может выглядеть исторически убедительно, но недостаточно ясно объяснять, почему JavaScript был важен именно в 1995–1997 годах.

### Инструкция агенту

Проверь страницу по `research.md` и `concept.md`.

Усиль связь между:

* появлением JavaScript;
* Netscape Navigator;
* интерактивностью;
* браузером как программной платформой;
* конкуренцией браузеров;
* началом стандартизации ECMAScript;
* рекламной идеей «научить браузер работать».

Не добавляй современные возможности JavaScript в историческую среду.

Сделай так, чтобы посетитель мог понять историческую ценность JavaScript даже без глубоких знаний программирования.

### Что изменилось

В блок 3 («Язык») добавлено пояснение: «JavaScript — это язык программирования, встроенный в браузер. Он позволяет странице выполнять команды и реагировать на действия посетителя.»

Раньше в блоке было только «Код не просто описывает информацию — он задаёт действие», что не объясняло природу JavaScript как языка программирования и его связь с браузером.

### Почему это сделало страницу содержательнее

- **research.md, раздел 1**: «JavaScript — язык программирования, который первоначально получил широкое применение внутри веб-браузеров» — добавленная фраза прямо соответствует этому определению.
- **research.md, раздел 7**: «язык оказался встроен непосредственно в браузер» — добавленная фраза объясняет эту связь.
- **concept.md, раздел "Что посетитель должен понять о JavaScript"**: «JavaScript появился внутри браузерной среды» — добавленная фраза раскрывает эту мысль.

Теперь посетитель понимает цепочку: JavaScript — язык программирования → встроен в браузер → позволяет странице выполнять команды → страница реагирует на действия посетителя.
