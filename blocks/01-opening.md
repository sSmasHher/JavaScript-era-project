# Первый экран — JavaScript Navigator School

## Назначение

Сразу сообщить посетителю, что перед ним реклама вымышленных курсов по новой технологии для веб-браузеров.

Первый экран должен создать ощущение 1996 года и одновременно заинтересовать человека возможностью сделать веб-страницу интерактивной.

## Содержание

Основной заголовок:

**JAVASCRIPT NAVIGATOR SCHOOL**

Подзаголовок:

**Научите браузер работать.**

Короткий текст:

«Ваши страницы уже показывают информацию. Теперь они могут реагировать на посетителя.»

Короткая историческая подпись:

**Курсы для создателей веб-страниц. 1996.**

## Связь с объектом

JavaScript появился как браузерная технология и позволил добавлять программируемое поведение веб-страницам.

## Связь с эпохой

Первый экран должен ощущаться как веб-страница второй половины 1990-х:

* плотная информация;
* простые прямоугольные элементы;
* текстовые ссылки;
* минимум современного декоративного дизайна;
* визуальный намёк на браузерную среду.

## Визуальные ориентиры

Netscape 1996, ранние образовательные веб-страницы 1996 года, Windows 95.

## Материалы

Исторический скриншот или стилизованный локальный визуальный материал браузера.

## Ограничения

Не использовать современный hero-блок с огромным заголовком, большим пустым пространством и современными CTA-кнопками.
