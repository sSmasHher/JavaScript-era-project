# Проблема — страницы умеют показывать, но не умеют реагировать

## Назначение

Показать исходную проблему, которую решает JavaScript.

## Содержание

Основная мысль:

**HTML рассказывает браузеру, что показать. JavaScript помогает объяснить, что делать.**

Короткое объяснение:

Ранний веб быстро развивался, но обычная веб-страница в основном оставалась документом. JavaScript добавил возможность выполнять сценарии в браузере и реагировать на действия пользователя.

## Связь с объектом

Этот блок объясняет историческую роль JavaScript как браузерного сценарного языка.

## Связь с эпохой

Формулировка должна быть рассчитана на человека 1996 года, который уже знает, что такое веб-страница, но ещё только знакомится с возможностью программировать её поведение.

## Визуальные ориентиры

Простая схема:

HTML → страница

JavaScript → действие

Браузер → выполняет сценарий

## Материалы

Текст, простая схема, небольшой фрагмент кода.

## Ограничения

Не использовать современные термины frontend, SPA, framework, component, full-stack.
