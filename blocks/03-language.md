# Язык — несколько строк, новое поведение

## Назначение

Показать JavaScript через небольшой фрагмент кода и объяснить его назначение без превращения страницы в учебник программирования.

## Содержание

Заголовок:

**Несколько строк могут изменить страницу.**

Показать небольшой простой пример JavaScript, связанный с реакцией страницы на действие пользователя.

Пример должен быть понятен визуально и не требовать знания современного JavaScript.

Основная мысль:

**Код не просто описывает информацию — он задаёт действие.**

## Связь с объектом

JavaScript является языком программирования, который в выбранный период использовался внутри браузера для создания интерактивного поведения.

## Связь с эпохой

Фрагмент кода должен выглядеть как учебный материал второй половины 1990-х:

* простой моноширинный текст;
* минимум подсветки синтаксиса;
* отсутствие современных редакторов кода;
* отсутствие терминала современного вида.

## Визуальные ориентиры

Моноширинный текст, простой прямоугольный блок, бумажная или учебная подача технического материала.

## Материалы

Короткий фрагмент JavaScript.

## Ограничения

Не использовать современный IDE-интерфейс, VS Code, DevTools или современные подсказки редактора.
