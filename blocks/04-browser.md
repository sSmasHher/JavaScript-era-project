# Браузер — новая программная платформа

## Назначение

Сделать главным историческим блоком страницы связь JavaScript и браузера.

## Содержание

Заголовок:

**Ваш браузер может больше, чем показывать страницы.**

Основная мысль:

JavaScript появился в Netscape Navigator 2.0 и позволил браузеру выполнять сценарии.

Показать небольшую временную шкалу:

**1995**
JavaScript появляется в Netscape Navigator 2.0.

**1996**
Internet Explorer 3.0 получает JScript.

**1996**
Начинается работа над стандартизацией.

**1997**
Принимается первая редакция ECMAScript.

## Связь с объектом

Блок показывает, как JavaScript прошёл путь от появления в одном браузере к необходимости стандартизации.

## Связь с эпохой

Визуально использовать плотную техническую хронологию, простые рамки и небольшие подписи.

## Визуальные ориентиры

Netscape 1996, архивы Ecma 1996, ранние веб-страницы.

## Материалы

Исторический скриншот браузера или веб-страницы, временная шкала.

## Ограничения

Не превращать блок в современную интерактивную timeline-компоненту.
