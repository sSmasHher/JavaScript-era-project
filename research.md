# Историческое исследование JavaScript

## 1. Что такое JavaScript

JavaScript — язык программирования, который первоначально получил широкое применение внутри веб-браузеров. Его появление позволило сделать веб-страницы не только документами для просмотра, но и интерактивными программными средами.

В современном понимании JavaScript связан с языком ECMAScript и большим набором браузерных возможностей. Однако для выбранной исторической эпохи важнее его первоначальная роль: выполнение сценариев непосредственно в браузере и добавление интерактивного поведения к веб-страницам.

Поэтому в рамках этого проекта JavaScript рассматривается прежде всего как технология, которая помогла превратить браузер из средства просмотра документов в среду, способную выполнять небольшие программы.

## 2. Кто и где создал JavaScript

JavaScript был разработан Brendan Eich в компании Netscape.

Язык создавался в контексте стремительно развивавшегося World Wide Web. Netscape занимала важное место на рынке браузеров, а браузер Netscape Navigator был одним из ключевых инструментов доступа к вебу.

Согласно документации Ecma International, JavaScript был создан Brendan Eich в Netscape и впервые появился в браузере Navigator 2.0.

## 3. Когда появился JavaScript

Ключевой момент произошёл в 1995 году.

JavaScript появился в Netscape Navigator 2.0 в сентябре 1995 года.

В дальнейшем JavaScript начал распространяться и в других браузерах. В 1996 году Internet Explorer 3.0 получил поддержку совместимой технологии Microsoft под названием JScript.

Таким образом, уже в течение короткого периода после появления JavaScript возникла необходимость в совместимости реализаций языка между браузерами разных производителей.

## 4. Какую проблему решал JavaScript

Ранний веб в основном воспринимался как система документов, связанных гиперссылками.

HTML позволял описывать структуру страницы, размещать текст, ссылки, изображения и элементы форм. Но для сложного интерактивного поведения страницы требовалась дополнительная возможность.

JavaScript позволил выполнять сценарии непосредственно в браузере.

Это означало, что разработчик мог описывать поведение элементов страницы, реагировать на действия пользователя и создавать более динамичные веб-интерфейсы.

В историческом контексте это было особенно важно потому, что браузер становился не просто просмотрщиком информации, а программной платформой.

## 5. Для кого был нужен JavaScript

Первыми непосредственными пользователями JavaScript были разработчики веб-страниц и веб-приложений.

Косвенными пользователями становились посетители сайтов: именно они взаимодействовали с результатом работы сценариев.

JavaScript был интересен разработчикам, которым хотелось сделать веб-страницы более интерактивными без превращения каждого действия пользователя в отдельный переход между статическими документами.

## 6. Где применялся JavaScript

В раннем периоде JavaScript прежде всего применялся внутри браузера.

Сценарии могли использоваться для:

* обработки действий пользователя;
* работы с формами;
* изменения поведения элементов страницы;
* создания интерактивных элементов;
* выполнения клиентских сценариев;
* создания более динамичного поведения веб-страниц.

Важно не переносить современные возможности JavaScript обратно в 1995–1997 годы. Современные серверные среды, сложные приложения, Node.js и современные фреймворки относятся к гораздо более поздним этапам развития экосистемы.

## 7. Почему JavaScript оказался важен именно для веба

Главная историческая особенность JavaScript заключается в том, что язык оказался встроен непосредственно в браузер.

Это создало связь:

**веб-страница → браузер → сценарий → действие пользователя**

Вместо полностью статичного документа веб-страница могла реагировать на человека.

Именно эта особенность соответствует формулировке варианта 25: браузер начинает рассматриваться как программная платформа, а веб — как среда интерактивных приложений.

## 8. Основные исторические вехи

### 1995 — появление JavaScript

Brendan Eich разработал JavaScript в Netscape.

В сентябре 1995 года JavaScript появился в Netscape Navigator 2.0.

Это отправная точка выбранной эпохи.

### 1996 — распространение технологии между браузерами

Internet Explorer 3.0 получил поддержку JavaScript-подобной технологии под названием JScript.

Это усилило проблему совместимости между браузерами и показало, что браузерный сценарный язык становится значимой частью веб-платформы.

### Ноябрь 1996 — начало стандартизации

Netscape начала работу с Ecma International над стандартизацией JavaScript.

Появление нескольких реализаций и конкурирующих браузеров сделало стандартизацию особенно важной.

### Июнь 1997 — первый стандарт ECMAScript

Первая редакция стандарта ECMAScript была принята Ecma General Assembly в июне 1997 года.

ECMAScript стал стандартизированной основой языка, связанной с JavaScript и JScript.

### 1998 — международная стандартизация

В 1998 году второй выпуск ECMA-262 был приведён в соответствие с международным стандартом ISO/IEC 16262.

Это уже выходит за основной период проекта, но показывает, к чему привела начавшаяся в 1996 году стандартизация.

## 9. Важные продукты и платформы

### Netscape Navigator

Netscape Navigator является главным технологическим окружением раннего JavaScript.

Именно в Navigator 2.0 JavaScript впервые появился как часть браузера.

### Internet Explorer

Internet Explorer важен для истории JavaScript как конкурентная браузерная платформа Microsoft.

В Internet Explorer 3.0 использовался JScript — реализация, связанная с тем же направлением браузерных сценариев.

### ECMAScript

ECMAScript — стандартизированная спецификация языка, связанная с первоначальными технологиями JavaScript и JScript.

Стандартизация была нужна для того, чтобы язык имел более единые правила реализации.

## 10. Что изменилось благодаря JavaScript

JavaScript не создавал World Wide Web и не заменял HTML.

Его значение заключалось в другом: он добавил программируемое поведение непосредственно в веб-страницу.

Это стало одним из шагов от веба как набора связанных документов к вебу как интерактивной программной среде.

Именно этот переход является главным смысловым центром нашего проекта.

## 11. Почему выбран период 1995–1997

Период 1995–1997 выбран не просто потому, что JavaScript появился в 1995 году.

В течение этих трёх лет происходит последовательность событий, которая позволяет увидеть переход от появления технологии к её превращению в стандартизируемую часть веб-платформы:

1. 1995 — JavaScript появляется в Netscape Navigator 2.0.
2. 1996 — аналогичная технология распространяется в Internet Explorer под названием JScript.
3. Ноябрь 1996 — начинается работа над стандартизацией.
4. Июнь 1997 — принимается первая редакция стандарта ECMAScript.

Таким образом, выбранный период показывает не только рождение языка, но и момент, когда браузерный сценарный язык становится частью более широкой технологической инфраструктуры веба.

## 12. Факты, которые можно превратить в рекламную идею

Для рекламной концепции особенно важны следующие факты:

* JavaScript был создан специально в контексте быстро развивавшегося веба.
* Его первой заметной средой распространения стал браузер.
* Браузер перестал быть только просмотрщиком документов и получил возможность выполнять сценарии.
* Между браузерами существовала конкуренция.
* Вскоре появилась необходимость стандартизации.
* JavaScript и JScript показывают, что одна технологическая идея могла существовать в разных реализациях.
* В 1995–1997 годах веб воспринимался как быстро меняющаяся новая технологическая среда.

Эти факты позволяют построить рекламу не вокруг абстрактного «ретро», а вокруг идеи:

**«Научись программировать саму страницу — пока браузер только начинает становиться программной платформой».**

## 13. Что не следует переносить в выбранную эпоху

В рекламной странице нельзя представлять JavaScript 1995–1997 годов так, будто уже существовала современная экосистема.

Не следует без исторического объяснения использовать:

* Node.js;
* npm;
* React;
* Vue;
* современные SPA;
* современные инструменты сборки;
* современные смартфоны;
* современные социальные сети;
* современные браузерные DevTools;
* современные облачные сервисы;
* современный дизайн SaaS-продуктов.

Они могут быть упомянуты только как более позднее развитие языка, но не как часть повседневной среды выбранного периода.

## 14. Неопределённости и важные оговорки

В популярных пересказах историю JavaScript часто упрощают до формулы «Brendan Eich написал язык за несколько дней».

Для учебного проекта не следует превращать эту популярную формулировку в центральный факт без дополнительной оговорки. Более надёжная формулировка — JavaScript был разработан Brendan Eich в Netscape в 1995 году в контексте создания браузерного сценарного языка.

Также важно не смешивать название JavaScript с ECMAScript.

JavaScript — историческое и коммерческое название языка и его реализаций, а ECMAScript — стандартизированная спецификация, развивающаяся через Ecma International.

## 15. Главный вывод исследования

Историческая ценность JavaScript для выбранной эпохи заключается не только в появлении нового языка программирования.

Главное изменение состоит в том, что веб-страница получила программируемое поведение непосредственно в браузере.

Поэтому JavaScript можно представить как один из инструментов перехода:

**от документа → к интерактивной странице → к браузеру как программной платформе.**
