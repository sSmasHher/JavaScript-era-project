Проблема — страницы умеют показывать, но не умеют реагировать

HTML рассказывает браузеру, что показать. JavaScript помогает объяснить, что делать.

Ранний веб быстро развивался, но обычная веб-страница в основном оставалась документом. JavaScript добавил возможность выполнять сценарии в браузере и реагировать на действия пользователя.

Язык — несколько строк, новое поведение

Несколько строк могут изменить страницу.

JavaScript — это язык программирования, встроенный в браузер. Он позволяет странице выполнять команды и реагировать на действия посетителя.

<!-- Простой сценарий для страницы --> <script> // Страница отвечает на действие посетителя function показатьПриветствие() { alert("Добро пожаловать на страницу!"); } </script> <!-- Кнопка вызывает сценарий --> <button onclick="показатьПриветствие()"> Нажмите меня </button>

Пример стилизован для учебных целей. Реальный синтаксис 1995–1997 годов отличался от современного JavaScript.

Браузер — новая программная платформа

Ваш браузер может больше, чем показывать страницы.

JavaScript появился в Netscape Navigator 2.0 и позволил браузеру выполнять сценарии.

1995
JavaScript появляется в Netscape Navigator 2.0
1996
Internet Explorer 3.0 получает JScript
1996
Начинается работа над стандартизацией
1997
Принимается первая редакция ECMAScript
Браузер Технология Год
